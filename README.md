# NOVA-AI: Asisten Pintar Otomasi Rumah Terintegrasi Web Dashboard & MCP

Project UTS Internet of Things (IoT) yang menghubungkan kecerdasan buatan (NOVA-AI) dengan kendali hardware ESP32 secara real-time menggunakan n8n dan Model Context Protocol (MCP).

## Fitur Utama
1. Kontrol Perangkat: Menyalakan dan mematikan 6 perangkat (Lampu, TV, Kulkas, AC, Mesin Cuci, Radio) melalui perintah AI.
2. Web Dashboard: Antarmuka web modern dengan pemantauan status perangkat secara langsung.
3. Sensor Monitoring: Membaca data suhu, kelembapan, dan jarak secara real-time.

## Komponen & Teknologi
- Mikrokontroler: ESP32, Sensor DHT11, Sensor Ultrasonic
- Backend & AI: n8n Workflow, Google Gemini AI (MCP)
- Frontend: HTML, CSS, JavaScript (Fetch API)
- Protokol: HTTP, JSON, CORS
